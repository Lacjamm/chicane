# Imported car models

These GLTF models were supplied by the project owner (downloaded from
Sketchfab for personal use in this hobby project). Each folder keeps its
original `license.txt` with the author credit — see those files for the
individual CC licenses and creators.

In-game they appear as the fictional Aegir / Vitesse / Ion / Talon lines;
no real-world branding is used in game data or UI.

| folder | in-game bodywork |
|---|---|
| jesko, jesko_attack | Aegir Konung — Jarl / Jarl Attack |
| agera_rs, agera_rs_cf, agera11, one1 | Aegir Konung — Vala RS / Vala Carbon / Vala Classic / Aegir One |
| agera_r_cop, one1_cop | VCPD Valkyr Unit patrol bodywork |
| divo, bolide | Vitesse Royale — Divergent / Boulder Track |
| i8 | Ion GT-e — Ion Coupe |
| m720gt3 | Talon GT3-R — GT3 Racer |
